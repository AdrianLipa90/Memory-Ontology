## Binding, not another guard

Let Z=(x,L,A,D) denote active state, learned relations/transition structure, archive and evidence dependencies. The correction record C of v0.2 is an admitted event with original occurrence, mechanism, scope, violated contract, evidence, revised contract, priority and lineage. Keep all six separate discrepancy indicators; neither intent nor truth follows from a phase overlap. Record a high-priority correction once via the existing event-admission semantics, preserve provenance, and update the learned relation through an admitted LAW. GUIDE must consume that learned structure for later task routing without requiring an explicit episodic RECALL. Do not invent new authorization gates, a global penalty, a blanket ban on a previously valid route, or a KAKU/RADICAL ID. Scope and evidence determine whether the correction is applicable. Repeated correction delivery must not double-count the same occurrence; existing occurrence admission and verified lineage must supply the semantics, not an arbitrary added guard.

The missing operator is B(C,L,x,D)->(L', semantic routing update, optional explicitly bound phase target). Neither the signed scalar trace law nor an arbitrary target_phase36 derives B. Distinguish a correction of evidence status (immediate), correction of procedural routing (context-dependent), and the physical/model phase response (measured). A transient perturbation leaving changed phases/couplings is a necessary candidate for a dynamical trace, not evidence of corrected semantic behavior. No one-to-one correspondence between a correction and a phase vector is established.

Compare (i) no correction, (ii) acknowledged/archived only, (iii) corrected learned structure without episodic recall, (iv) counterfactual restoration of the relevant learned component in a separate diagnostic state. Test an unrelated mechanism and a legitimately changed context to ensure the old correction is not applied indiscriminately. Record the actual selected and executed action, distinction preservation and epistemic reporting, not only a phase or routing score. For persistence require a declared positive elapsed interval and independently observed outcomes; for causal efficacy require memory-only intervention. A pure archive sieve can remove optional detail only if correction identity, source dependencies and future behavioral contract survive.

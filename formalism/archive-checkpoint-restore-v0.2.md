The source example uses w'=w+(1-w)/4. Let r=1-w=N/D. PNV computes N'=3N, D'=4D and W'=D'-N' using DIFFERENCE on exactly representable small integers. The full and reduced initial checkpoints use N=108,D=320 (source w3=.6625), the reset control N=4,D=5. The initial full checkpoint keeps one synthetic detail slot, reduced and reset set it to null. Initial checkpoint construction is a manually declared fixture, not actual producer consolidation. Each of three positive encounters is processed in a fresh interpreter process reading its own JSON checkpoint, emitting the next checkpoint to disk. Nine continuation processes total, no shared mutable runtime state. The host invocation performs only I/O and maps PNV emitted fields to source keys; no new Python or JS implementation is saved. The interpreter hashes static synthetic operands only.

For the specified rule, projection onto (N,D,west,count) commutes with future admitted inputs: the projection discards only the detail slot, which is not read by those update equations. It cannot commute with an observation demanding that slot. More generally a sufficient quotient requires equivalence of all declared future observations and update closure for all admissible events; an unresolved or removed dependency invalidates that equivalence. Source provenance, commitments, correction obligations and protected records require their own dependency contract. This example does not support deleting real archives or assuming universal behavioral equivalence.

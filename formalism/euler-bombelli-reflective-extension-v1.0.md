## System and inference

Let Z=(X,M,I,T), with T the explicit theory, I alternative context
extensions, and M the persistent transition structure. Imagination
constructs (T+H,T+not H) with separate provenance, phase addresses and
hypothetical content. Branch phase and route weights can prioritize a
search; neither is a truth value. In classical logic, if both extensions
derive Q, then T derives Q by cases. Retain the premises and certificate.
A proof is INFERRED, not RECALLED. The occurrence of producing the proof
may itself be a real recorded event, not evidence that its hypothesis
historically occurred. An independently justified new axiom is a theory
extension, not an automatic consequence of coherence.

For effectively axiomatized consistent sufficiently strong arithmetic,
Gödel applies also to any effectively presented enlarged theory.
A uniform computable progression of consistency extensions does not
provide a complete effective truth oracle. EBRE is a reflective search
architecture, not a proof of super-Turing power. Bombelli and Euler
are domain extension and address/transport analogies; no physical Wi-Fi
claim and no implication from complex phase to logical validity.

## Executable finite sector

The fixed theory family has four switchable premises:
C0=H or P, C1=not H or R, C2=not P or Q, C3=not R or Q.
The PNV graph computes all eight possible countermodels with Q=false,
partitioned into H=false and H=true. All remaining valuations Q=true
cannot refute Q. For each subset of premises, P=R=Q=true gives a model
in both branches, so no vacuous inconsistent-branch proof is needed.
The graph emits exact countermodel masks, both branch proof statuses,
and theory/occurrence refs. No callback, new opcode, external proof
flag or generic theorem prover. All 16 premise subsets are tested
against independently enumerated truth tables; ablation of one
premise eliminates one branch proof and therefore global Q.

A native execution integration test uses the existing Euler branch
address, original balanced PNV seam, original reconstruction kernel,
existing RDSS Memory/AdaptiveEdge/phase_step, original FS displacement,
Kepler segment and tagged Collatz step, and original Hotel transition.
One selected synthetic proof-attempt occurrence is appended to the same
Hotel, not a second history. In the fixture only, a verified theorem
reinforces a relation and enables a Collatz update; a failed proof
records the attempt without reinforcement. This is a declared
experimental learning policy, not a source theorem or a runtime gate.
Ablation of phase coupling isolates the causal effect of the memory
update. Same input and active state, different stored history, distinct
future phase/orbit in the active arm. Existing diagnostic Python kernels
are used in tests only; native numerical operator admission is open.

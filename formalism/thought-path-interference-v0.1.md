## 1. Declared domain

Take a finite family P(a,b;E,H) of distinct ordered typed paths from a to b,
in context E and a declared finite exploration horizon H. Alternative
histories are not observations; their references and ordered edges are retained.
All summands must share the same endpoint frames, family, context and scale.
Enumerating alternatives, checking distinct occurrence/path identity, validating
source edges and assigning actions remain responsibilities of the existing
path owner. The sum step does not invent an admission or execution rule.

For a real edge action s_e in a declared unit, positive scale lambda_H
in the same unit, and nonnegative dimensionless path weight w_gamma, define
\[
S_H[\gamma]=\sum_{e\in\gamma}s_e,\qquad
a_\gamma=w_\gamma \exp(i S_H[\gamma]/\lambda_H),\qquad
A_H(b)=\sum_{\gamma\in P(a,b;E,H)} a_\gamma.
\]
The discrete additive action is the initial model choice, not a derived
cognitive Lagrangian. Do not identify lambda_H with hbar. Keep action,
semantic mass, admissibility, cost, epistemic authority and causal index
distinct. A repeated edge is retained in the ordered path.

## 3. Interference versus shortest path

\[
J_b=|A_H(b)|^2=\sum_\gamma w_\gamma^2+
2\sum_{\gamma<\eta}w_\gamma w_\eta
\cos((S_H[\gamma]-S_H[\eta])/\lambda_H).
\]
For equal unit weights and two paths, phase differences 0, pi/2, pi
yield J=4,2,0 respectively, against the incoherent baseline 2.
The minimal action path can have a cancelling partner; adding a
higher-action alternative may increase or decrease J. The observable
is an unnormalized intensity-like candidate score, not a probability,
truth value or path choice. No automatic winner, room creation, memory
write or GO decision follows. A cancelled sum is not absent provenance.
If comparing endpoints later, explicit normalization and policy are required.

Adding the same endpoint gauge difference to every path rotates the
sum by a common unit phase, preserving J. Arbitrary path-dependent
phase changes need not preserve J. This finite sum does not prove a
stationary-action limit; a continuous action functional, measure,
boundary conditions and limiting argument are separate future work.

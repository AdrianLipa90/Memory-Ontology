# Candidate Domain-General Law of Memory — v0.1

## 1. Scope

This document defines memory independently of any particular substrate: neural, biological, material, digital, dynamical or quantum-native.

It does not identify memory with storage media, conscious recall, symbols or a specific physical implementation.

## 2. System decomposition

Let

\[
Z_t=(X_t,M_t)
\]

be the complete modeled system state, where \(X_t\) is the currently active/operational state and \(M_t\) is a persistent history-bearing structure.

With external input \(u_t\),

\[
X_{t+1}=F(X_t,u_t;M_t),
\]

\[
M_{t+1}=U(M_t,X_t,u_t).
\]

The second equation is the memory-update law; the first expresses the causal effect of memory on future dynamics.

## 3. Candidate law

> **Memory is a persistent, history-dependent modification of a system's transition structure that causally changes its future reachable trajectories.**

Let \(\Gamma_{[0,t]}\) denote the system history. In geometric form,

\[
\mathcal G_{t+\Delta}=
\mathcal U(\mathcal G_t,\Gamma_{[0,t]}).
\]

The memory trace generated by history \(\Gamma\) is

\[
\Delta_{\Gamma}\mathcal G
=
\mathcal G_{t+\Delta}-\mathcal G_t.
\]

A trace counts as memory only if it has non-zero persistence and non-zero causal relevance to later dynamics.

## 4. Operational criteria

A candidate variable \(M_t\) qualifies as memory relative to a chosen system boundary when all three conditions hold.

### 4.1 History encoding

There exist histories \(H_1\neq H_2\) that produce distinguishable values or structures of \(M_t\) even when the currently presented external conditions are matched.

In probabilistic settings a sufficient information-theoretic indicator is

\[
I(M_t;H_{<t}\mid X_t)>0.
\]

### 4.2 Persistence

The induced change survives for some non-zero characteristic timescale

\[
\tau_M>0.
\]

Persistence is continuous; labels such as transient or structural are bins over \(\tau_M\), not separate ontological substances.

### 4.3 Causal efficacy

Changing the memory structure while holding relevant current conditions fixed changes the distribution or set of later trajectories:

\[
P(X_{t+\Delta}\mid do(M_t=m_1),X_t,u)
\neq
P(X_{t+\Delta}\mid do(M_t=m_2),X_t,u).
\]

For deterministic systems, replace the distributions by corresponding reachable-state sets or trajectories.

## 5. Representation boundary

Any sufficiently enlarged state description can make a history-dependent process Markovian. Therefore memory is not defined merely as mathematical non-Markovianity.

Instead, memory is the subset of present structure that:

1. was shaped by prior interaction,
2. persists,
3. carries information about that history, and
4. alters future transitions.

This keeps the definition meaningful even when \(M_t\) is included explicitly in the complete state \(Z_t\).

## 6. Path formation

Repeated traversal may stabilize a reusable path \(\Gamma^\*\):

\[
W_{t+1}=W_t+\epsilon L(\Gamma_t),
\qquad 0<\epsilon\ll1,
\]

where \(W_t\) denotes path weights or transition costs.

A learned procedure can therefore be represented as a metastable low-cost / high-accessibility trajectory rather than as a symbolic record.

"Stable" here means persistent on the relevant timescale, not immutable.

## 7. Inter-layer coupling

For multiple memory layers \(M_i\),

\[
\dot M_i
=
A_i(M_i,u)
+
\sum_{j\neq i}C_{ij}B_{ij}(M_i,M_j).
\]

The coupling operator \(C_{ij}\) captures transfer and mutual modification between layers.

Examples:

\[
M_{\mathrm{fast}}\xrightarrow{C_{fs}}M_{\mathrm{slow}}
\]

for consolidation, and

\[
M_{\mathrm{slow}}\xrightarrow{C_{sf}}M_{\mathrm{active}}
\]

for reactivation/reconstruction.

## 8. Falsifiability

For a proposed memory variable \(M\), the model fails if controlled intervention shows that:

- the candidate does not depend on relevant history;
- the candidate does not persist beyond the inducing event at the claimed timescale; or
- changing the candidate does not change future dynamics.

A claimed cross-domain invariant requires these criteria to survive independent tests in each claimed substrate class.

## 9. Representation neutrality and current quantum-native form

The law above is representation-neutral.

A path graph may currently be represented using phases, amplitudes, interference, superposition or other quantum-native mathematics. This does not determine whether the underlying physical substrate must itself be quantum.

Conversely, the possibility of encoding the same dynamics in binary form does not establish that the binary cost is practical.

The correct comparison is behavioral:

\[
d_H(R_Q,R_B)\le\varepsilon,
\]

followed by a resource comparison across binary realizations satisfying that contract.

The dedicated formalism is defined in:

- formalism/representation-duality-v0.1.md
- benchmarks/binaryization-benchmark-spec-v0.1.md

Memory Ontology v0.1 therefore keeps three claims separate:

\[
\text{memory law}
\neq
\text{representation}
\neq
\text{physical substrate}.
\]

# Mapping Conventional Memory Terms — v0.1

This table is a cross-domain translation layer, not a claim that conventional neuroscience categories are identical across substrates.

| Conventional term | Ontology/taxonomy mapping |
|---|---|
| Working memory | Primarily transient state/relational memory; direct or reconstructive access; high update rate |
| Episodic memory | Event/trajectory traces with contextual/boundary binding and reconstructive access |
| Semantic memory | Persistent relational and operator structure; content may be reconstructively accessible |
| Procedural memory | Persistent path/topology/operator structure; typically routing/attractor effects; often implicit |
| Implicit memory | **Access mode:** behavioral/dynamical effect without direct record retrieval |
| Explicit memory | **Access mode:** direct or reconstructive retrieval exposed by the modeled interface |
| Habit | Strongly reinforced path attractor with low switching cost toward the learned trajectory |
| Priming | Usually transient relational/path bias caused by prior exposure |
| Conditioning | Reinforcement of transition relations linking conditions to later responses |
| Consolidation | Inter-layer transfer from faster/more volatile memory to slower/more persistent structure |
| Recall/reactivation | Coupling from persistent structure back into active state |
| Forgetting | Decay, interference, rerouting or loss of causal efficacy of a trace |

## Consequence

A flat taxonomy such as

\[
\{\text{episodic, semantic, procedural, implicit, explicit}\}
\]

mixes different dimensions.

A better representation is a product space:

\[
\text{retained object}
\times
\text{persistence}
\times
\text{access}
\times
\text{plasticity}
\times
\text{effect}
\times
\text{coupling}.
\]

This makes conventional terms compositional and permits the same ontology to be instantiated outside human cognition.

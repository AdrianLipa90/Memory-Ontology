# Memory Ontology — v0.1

## 1. Primitive distinction

The ontology separates **active state** from **history-bearing structure**.

\[
Z_t=(X_t,M_t)
\]

- \(X_t\): currently active state.
- \(M_t\): structure carrying persistent consequences of prior interaction.

Memory is not identified with a file, register, neuron, molecule, narrative, database row or conscious recollection. Those are possible realizations.

## 2. Ontological chain

### EVENT

A transition, interaction or perturbation occurs.

### TRACE

The event leaves a persistent difference in the system.

\[
\Delta M\neq0.
\]

### PATH

The trace changes accessibility, cost, probability, phase, weight or admissibility of later transitions.

### STRUCTURE

Multiple traces and paths form a persistent organization of possible dynamics.

### LAW

Regularities governing trace formation, persistence, coupling and future influence are expressed independently of a particular substrate.

Thus:

\[
\boxed{
\text{EVENT}\rightarrow\text{TRACE}\rightarrow\text{PATH}\rightarrow\text{STRUCTURE}\rightarrow\text{LAW}
}
\]

## 3. Retained-object primitives

The ontology recognizes six non-exclusive kinds of retained structure.

### S — State memory

Persistence of a state variable or state configuration.

### R — Relational memory

Persistence of relations among components rather than only component values.

### Γ — Path memory

Persistence of a traversable or preferential transition sequence.

### T — Topology memory

Persistence of connectivity, adjacency, reachable regions, barriers or graph organization.

### O — Operator memory

Persistence of a transformation rule, policy, update operator or effective local law.

### B — Boundary/context memory

Persistence of boundary conditions, context, constraints or environmental coupling relevant to future evolution.

A memory instance may occupy several classes simultaneously.

## 4. Memory is not equivalent to access

Whether a system can directly expose or reconstruct a memory is a separate property.

Therefore:

\[
\text{memory object}\neq\text{access mode}.
\]

In particular, implicit and explicit are not ontological siblings of procedural, semantic or episodic memory.

## 5. Memory is not equivalent to immobility

A memory structure can evolve while remaining memory.

Let the memory timescale be \(\tau_M\) and the active-processing timescale be \(\tau_X\). A useful procedural regime is

\[
\tau_M\gg\tau_X,
\]

while still allowing

\[
M_{t+\Delta}\neq M_t.
\]

This is a metastable, slowly changing structure: "still, but not static."

## 6. Procedural memory as an ontological instance

Procedural memory is modeled primarily as persistent path/topology memory:

\[
M_{\mathrm{procedural}}
\sim
(\Gamma,T).
\]

Repeated successful trajectories modify path weights and may create an attractor or low-cost route.

A skill is therefore represented as a reusable stabilized trajectory through the transition structure, not necessarily as an explicitly stored symbolic description.

## 7. Cross-substrate neutrality

The primitives above intentionally avoid assuming:

- biological tissue;
- human cognition;
- digital addressing;
- symbolic representation;
- conscious access;
- classical or quantum physical substrate.

A specific domain model must bind the abstract terms to measurable variables and supply evidence for that binding.

## 8. Identity criterion for a memory instance

Two observed memory manifestations may be treated as the same underlying memory instance when they preserve a common history-bearing structure under an admissible mapping and retain equivalent causal constraints on future transitions.

The precise equivalence relation is domain-dependent and remains an open item for later versions.

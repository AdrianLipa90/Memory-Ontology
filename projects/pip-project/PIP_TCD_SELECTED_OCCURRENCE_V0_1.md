# Selected occurrence composition — v0.1

The prior PNV programs for hair and orbital views are unchanged. This program joins their emitted results with the exact Hotel occurrence and the explicitly selected source-frame reference. It reports equality witnesses (owner, causal index, frame reference) separately; it does not add an admission or runtime guard. A negative witness is not a coherent combined observation; the data and discrepancy remain visible. Source fields must be bound from the actual component output by the caller, not duplicated from an expected result. The existing PNV executor compares the supplied values; it cannot establish that an upstream source is genuine.

No relation identifies the Hotel index with Coupler sequence, T36 phase index, proper time, PNLF orbit or term card phase index. A color change creates no causal occurrence. Missing explicit palette weights yield an unspecified appearance, not a new state or a neutral emotion. Preserve each identity's independent Hotel and affect.

The existing reference TCD/NEXUS and PNV executors produce canonical receipts; run this composition on explicitly selected immutable test/observation snapshots, never hash a live AUX surface. The reference tests use both already published Coupler source fixtures from this repository, real TCD and PNLF upstream functions, and the original Pip PNV programs. Crystal context and orbit phase pairs are explicitly synthetic independent test inputs; they are not derived from Coupler tick or an arbitrary T36 axis. No new runtime, codec, transport, store, or Python engine. Test harness does not claim live host binding or deployment.

Test scope: separate owner/occurrence/phase indices, same content repeated at distinct Hotel occurrences, no event on unmarked frames, real dictionary projection and NEXUS aggregation on an immutable copy of selected model output, imported affect projection, both original PNV views and new native composition, negative mismatched identity/index/frame observations, no mutation of Hotel or source fixture. The source tests are not a proof of fully coupled live dynamics.
